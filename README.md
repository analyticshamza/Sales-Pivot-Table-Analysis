# Sales-Pivot-Table-Analysis
This project is a beginner-friendly Excel-based data analysis exercise focused on learning how to use **Pivot Tables** to extract insights from a small business sales dataset.

## 📁 Project Structure

| Sheet Name                | Description |
|--------------------------|-------------|
| `Raw_Data`               | Original dataset containing sales details like product category, revenue, order quantity, profit, cost, discount, and region. |
| `Revenue_By_Category`    | Pivot Table showing the **total revenue** for each product category. |
| `Profit_Margin_By_Product` | Pivot Table with a **calculated field** showing profit margin (`Profit / Cost`) by product category. |
| `Region_Filter_Slicer`   | Interactive Pivot Table with a **slicer** allowing filtering by region to analyze sales data dynamically. |

---

## 📌 Key Skills Demonstrated

- Creating and formatting Pivot Tables in Excel
- Using calculated fields for deriving custom KPIs (e.g., Profit Margin)
- Using slicers for interactive filtering
- Structuring and presenting data-driven insights
- Working with Excel formulas like `=Profit/Cost` and formatting as percentages

---

## 📊 Dataset Overview

The dataset contains the following fields:

- `Product Category`
- `Revenue`
- `Order Date`
- `Order Quantity`
- `Cost`
- `Profit`
- `Discount`
- `Region`

---

## 📈 Sample Insights

- **Furniture** had the highest profit margin (~30.77%)
- **Clothing** generated the highest total revenue
- The **average profit margin** across all categories was ~22.73%
